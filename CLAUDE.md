# Project Instructions

## Project
AI-assisted development capstone project.

## Stack
- Node.js
- JavaScript
- HTML
- CSS
- MySQL

## Coding Conventions
- Keep the code simple and readable.
- Use clear and descriptive names for variables and functions.
- Keep functions small and focused.
- Avoid unnecessary dependencies.
- Add comments when they help explain complex code.

## Git Conventions
Use Conventional Commits for all commit messages.

Examples:
- feat: add user authentication
- fix: fix login validation
- docs: update README
- chore: update configuration
- refactor: improve project structure

## AI Assistant Rules
- Explain important changes clearly.
- Do not make unrelated changes.
- Ask before making major architectural changes.
- Keep the project beginner-friendly.
